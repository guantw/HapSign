## Security and support notice

Official HapSign binaries intentionally use **no trusted publisher identity** and are not notarized.
The macOS arm64 CLI contains only the mandatory identity-less ad-hoc signature generated by
PyInstaller. Do not bypass operating-system or organization security controls. If publisher code
signing is required, build and sign the binaries from source.

Verify downloads with `SHA256SUMS`, `release-manifest.json`, and the GitHub artifact attestation.
Linux Portable targets Ubuntu 22.04 x64; other distributions are experimental. macOS supports
arm64 only; macOS x64 is unsupported.

This is a debug-signing tool for authorized HAPs, not an AppGallery production-signing service.
Account login, CAPTCHA, 2FA, and consent remain user-driven.
